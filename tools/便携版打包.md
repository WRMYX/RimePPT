# 便携版打包

安装 PowerShell 7.2 或更高版本，在项目根目录执行：

```powershell
pwsh -NoProfile -File tools/Build-Portable.ps1
```

脚本每次重新发布当前源码，包含 .NET 和 Windows App SDK 运行文件，并把带时间戳的 ZIP 输出到 artifacts。发布过程使用独立的临时构建目录，避免正在运行的预览程序占用输出文件。

压缩包结构：

```text
RimePPT/
  RimePPT.exe
  *.dll                 .NET、WinUI 及程序依赖
  Assets/
  en-us/
  zh-CN/
  ...                   其它必要运行资源
```

只保留简体中文与英文回退语言资源，剔除调试符号。资源保持在原有相对路径，不把 DLL 随意搬到其它子目录，不启用可能破坏 WinUI/COM 的裁剪。

解压后直接双击 RimePPT.exe。压缩包不包含 CMD 启动器或使用说明。设置和笔迹仍保存于当前用户的 LOCALAPPDATA，不随程序文件夹移动。旧 ZIP 和用户已解压目录不会被脚本覆盖。
